# Security Policy

We take the security of Ekklesia Voting Tech seriously. If you discover a
security vulnerability, please do not open a public issue.

Report it privately to:

- Adam Dean, adam@crypto2099.io
- Mad Orkestra, mad@madorkestra.com

Include a description of the vulnerability, steps to reproduce, and any
relevant logs or proof-of-concept code. We will acknowledge receipt within
5 business days.
